# Naming and trademark notes

The product name is **CohortKit**. This file records what we know about the name so future maintainers don't have to redo the research.

## What we checked (September 2026)

- **Product collisions**: "AcceleratorOS" and "CohortOS" are used by existing companies in adjacent space; we avoided them. "OpenCohort" is taken by a Web3 protocol.
- **Web search for "CohortKit"**: no existing product, company, or registration found using the exact name.
- **"COHORT" word marks**: several live US/EU registrations exist in software and other classes (e.g., EPIC Systems in Class 9, a college-admissions product in Class 9/42, an EU financial-software company). None uses the "CohortKit" mark, but "cohort" as a stem is crowded in software.

## What this means

- The exact mark "CohortKit" appears available for filing, but this was a best-effort web search, **not** a professional clearance search of USPTO/EUIPO registers.
- Before a commercial launch, get a trademark attorney opinion and file a word-mark application (US Class 9/42) for CohortKit.
- Until registration, use the name with a ™ designation and keep records of first use in commerce.

## Renaming (if ever needed)

The name is centralized in few places: `package.json`, `index.html` title, the `Brand` component in `src/ui.tsx`, and copy strings in `src/App.tsx`. A rename is a search-and-replace plus a new repository URL.
